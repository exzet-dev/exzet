# **Contributing to Exzet**

Thank you for considering contributing to Exzet! Follow these guidelines to ensure a smooth development experience.

---

## **Getting Started**

1. **Fork the Repository**:
   - Clone your fork:
     ```bash
     git clone https://github.com/your-username/exzet.git
     cd exzet
     ```

2. **Set Up Development Environment**:
   - Run the setup script:
     ```bash
     ./scripts/setup-dev-env.sh
     ```

---

## **Reporting Issues**

- Use the [GitHub Issues](https://github.com/exzet-dev/exzet/issues) page to report bugs or feature requests.

---

## **Coding Guidelines**

- Follow idiomatic practices for Go, JS, Bash, etc.
- Write clear and concise commit messages.
- Ensure all tests pass before submitting a PR.

---

## **Submitting a Pull Request**

1. Create a new branch:
   ```bash
   git checkout -b feature/new-feature
   ```

2. Push changes and create a PR:
   ```bash
   git push origin feature/new-feature
   ```
3. Reference related issues in your PR description.
